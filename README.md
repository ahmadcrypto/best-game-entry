**Lantern Ferry** — a complete original 2D canvas game: sail a little ferry across a night river, gather the lost wisps, light all six lighthouse lamps, and dodge the drifting mines. Three hearts, a dash with a cooldown, a combo that grows with each delivery, and a win the moment the sixth lamp burns. Keyboard (WASD/arrows + Space) and mouse, with synthesized WebAudio sound and no assets, no network, no build step.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Or open `game/index.html` from any static file server. `main.ts` (Node 22, standard library only) hands the entry in: it copies `game/` and `screenshots/` to `/output` and writes `/output/dossier.json`.
